1. `/loop` command (loop current track / queue).
2. `/play` with no arguments unpauses instead of requiring a query.
3. Playlist links accepted: enqueue everything with no queue cap (YouTube `list=`, SoundCloud `/sets/`, Spotify playlist, ...). Playlists are the only QUEUE_MAX exception (otherwise 50); private/unavailable playlist is a new error.
4. Automatic link cleanup: strip unsupported parameters (e.g. radio/start params) and keep just the track link instead of refusing.
5. Allow Spotify track and playlist links as metadata sources (resolve via YouTube/SoundCloud search, no direct playback; currently refused — track/episode → SPOTIFY, album/playlist/show → PLAYLIST).
6. SoundCloud-first when input link is SoundCloud (03/05 mismatch follow-up).
7. YouTube `watch?v=&list=&start_radio=` auto-cleanup vs refuse (02) — extends #4.
8. `/remove` already shows position after fix; consider same for `/skip` target echo.
9. Auto-updating queue message (live edit every ~10 s or on track change).
10. Idle 7–10 min + paused-30-min auto-leave timings (retune IDLE_DISCONNECT_S + new PAUSED_DISCONNECT_S).
11. Stuttering over time: profile DAVE/JDAVE, youtube-source cipher, GC/CPU, network jitter.
12. MAN-VOICE-01 expectation: auto-join is accepted behavior, update test to match code.
13. MAN-PLAY-13 / MAN-IMPORT-09: after recall batch QUEUE_MAX=50 and IMPORT_MAX_TRACKS=50; tests fill to 45/50, not 195/200.
14. Import recall residual (measured after slices 5+15 land: enqueued over detected on clean prints; if <90%, then duration/channel-aware ranking, official-audio boost, retune VERSION_PENALTY vs threshold — otherwise no change).
15. Mid-track cuts: auto-advance only on mayStartNext, retry once on FriendlyException, cipher/client fallback, DAVE stats log, stuck-track watchdog.
16. Cancel/Remove confirmation: if red embed still feels weak, delete preview message + send ephemeral summary with counts.
17. More than 5 images: paginated preview or 10-image support with per-image progress instead of dropped-images footer.
18. SoundCloud search robustness: `Did not detect any supported formats` falls back to cleaned YouTube query with backoff, counts as not-found only after both fail.
19. YouTube format warnings: prefer music clients, skip video-only adaptive sets when audio is missing.
20. OCR dark-print calibration: PSM/Otsu/cover-art handling if title/artist pairing fix still below target.
21. Queue permission model: clarify who can `/remove` others items (importer-only vs anyone) and document MAN-QUEUE-02 expectation.
